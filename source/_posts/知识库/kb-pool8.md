## 先看一局是怎么走完的

台面固定有 <strong>15 颗目标球</strong>，加一颗白色母球共 16 颗。号码分三段：<strong>1—7</strong> 是一组，整块带色，常见叫法是全色或实心。9—15 是另一组，中间一道白、两边带色，常见叫法是花色或半色。8 号是黑球，留到最后打。

主线只有一条：<strong>先把自己一组的 7 颗全部落袋，再打 8 号</strong>。进哪个袋口通常要事先交代：多数地方要求打进指定袋口，也有房规只要求任意一袋。提前把 8 号打进、或犯规时一起落袋，一般直接判负，各地处理也有差异。

![图 1](/images/kb/pool8/pool8-fig1.svg)*图 1｜三角框里五行球的示例位置，各地摆法并不统一；图上标出的约定只有第三排正中放 8 号、最前一颗对准置球点。*

## 上手流程：第一次玩照着做

- 把球塞进<strong>三角框</strong>立在置球点上，抽框后开球。多数摆法把 8 号留在第三排正中，其余细节各地不一。
- 在开球线后<strong>冲球</strong>把球堆打散；开球怎样才算合法各地并不统一，开局前问一句最省事。
- 开球进球后定不定组，两种做法都常见：有的当场定组，更多房规要求开球后第一杆才算。
- 轮流出杆，出杆前想两件事：这颗球往哪个袋口走、母球<strong>走位</strong>到哪。
- 本组打完，双方确认黑球袋口（是否要指袋以当场约定为准）再收尾。

## 核心规则

- <strong>先碰本组</strong> — 母球第一个碰到的必须是本组的球。先碰对方的球或 8 号，多数规则记作犯规。
- <strong>进球才继续</strong> — 打进本组的球就能接着打，一颗没进就换人。
- <strong>黑球收尾</strong> — 本组 7 颗全部落袋后才轮到它。常见约定是先报袋口再打，也有地方不要求指袋。
- <strong>犯规怎么罚</strong> — 母球落袋、未碰到任何球、球跳出台面、推杆双碰都是常见犯规。多数地方让对手拿<strong>手中球</strong>自由摆放母球，也有线后开球或只罚球的旧式房规，并不统一。

## 出杆：击球点在母球上

把母球想成一个钟面：打中心是中杆，上半部是高杆，下半部是低杆，左右两侧就是加塞。点位越靠边越容易打偏，所以高杆低杆与加塞建议先小幅度练。

![图 2](/images/kb/pool8/pool8-fig2.svg)*图 2｜五个击球点的相对位置：中心一点、上下各一点、左右各一点，右侧四行为图上说明。*

## 走位：进球只是半步

同一杆有三条线：母球撞向目标球、目标球飞向袋口、母球撞后停在何处。新手只盯第二条，往往球进了、母球却卡在难打的位置，照样换人。出杆前先定母球落点，再决定打哪颗。

![图 3](/images/kb/pool8/pool8-fig3.svg)*图 3｜三条线分别是母球接近目标球、目标球飞向袋口、母球撞后停位；编号对应图上三个箭头。*

## 术语速查

球桌上会被说出口的词，同一件事各地叫法不同。

| 术语 | 类别 | 含义 |
| --- | --- | --- |
| 母球（白球） | 器材 | 球杆直接击的那颗，两个叫法指同一颗。 |
| 目标球 | 器材 | 被撞击的球，即分到各组的那些。 |
| 分组 | 规则 | 常见是开球后先进的那组定人，也有抽签定的。 |
| 开球／冲球 | 规则 | 打散球堆的第一杆，怎样算合法各地并不统一。 |
| 落袋／进袋 | 规则 | 球进袋口并留下，俗称进球。 |
| 袋口（角袋／中袋） | 器材 | 台面六处开口：四角是角袋，长库边中间是中袋，常见后者更难进。 |
| 库边（库） | 器材 | 四周弹起的边胶，走位多靠它反弹。 |
| 置球点 | 器材 | 台面标记点，摆球时常见让最前一颗压住。 |
| 摆球／三角框 | 规则 | 开局码球用的框，各地摆法并不统一。 |
| 指袋（报袋） | 规则 | 出杆前呼叫袋口；是否必须各地不同，多数只在收尾要求。 |
| 走位 | 技巧 | 让母球停在便于打下一颗处，也叫叫位。 |
| 高杆／低杆／中杆 | 技巧 | 击母球上部、下部、中部的统称。 |
| 加塞 | 技巧 | 击点左右偏移带上旋转，越大越容易打偏。 |
| 弧线球（扎杆） | 技巧 | 高抬杆尾让母球走弧线绕过阻挡。 |
| 跳球 | 技巧 | 让球跃过阻挡的打法，各套规则写法并不统一。 |
| 贴球 | 状况 | 两球几乎贴住，各地处理差别明显，先讲清再打。 |
| 斯诺克（做障碍） | 战术 | 用别的球挡住出杆线路，叫法从英式台球借来。 |
| 清台 | 战术 | 一杆接一杆打完本组再收尾。 |
| 黑八 | 规则 | 既指 8 号球，也指整套玩法。 |
| 手中球（自由球） | 规则 | 对手犯规后常由你摆母球，范围各地不同。 |
| 线后开球 | 规则 | 较老的罚法：母球放开球线后重冲，部分地区仍用。 |

## 新手最常踩的坑

> <strong>坑一：只想进球，不想母球停在哪儿。</strong>多半一杆就换人。出杆前先定走位，把母球落点当第二目标。
> <strong>坑二：开球用尽全力。</strong>大力冲球最容易把母球送进袋口，多数房规把手中球白送对手，七分力通常更划算。
> <strong>坑三：本组最后一颗没清就把黑球打进袋口。</strong>属于提前结束，一般直接判负，也有地方只重摆。
> <strong>坑四：贴球时乱发力。</strong>两球贴住还硬冲，容易被判双碰或推杆；先和对方确认怎么处理再出杆。
> <strong>坑五：加塞过猛，母球飞出台面。</strong>这是跳出台面的犯规，多数地方交给对手手中球，小塞起步更稳。
> <strong>坑六：没确认袋口就宣布自己赢了。</strong>收尾时是否要指袋各地不一，先把话说清再出杆。
> <strong>坑七：把中式八球的规矩照搬到每张球桌。</strong>开局前对齐三件事：是否指袋、犯规给手中球还是线后、三角框怎么码，多数争论都出在这几处。

## 一页速查

| 要记的事 | 结论 |
| --- | --- |
| 台面球数 | 目标球 15 颗，加母球共 16 颗 |
| 分组号段 | 1—7 一组、9—15 一组，8 号最后 |
| 胜利主线 | 本组全部落袋后，再把黑球打进约定的袋口 |
| 常见犯规 | 母球落袋、空杆未碰球、先碰对方组或 8 号、球跳出台面、推杆双碰 |
| 犯规处罚 | 多为对手手中球自由摆放，也有线后或只罚球的房规 |
| 是否指袋 | 各地不统一，常见只在收尾时有要求 |
| 练功顺序 | 先中杆准度，再高杆低杆，最后练加塞与弧线球 |

> <strong>关于“各地不一样”：</strong>本页只把最常见的主线写死：1—7 与 9—15 分组、先碰本组、打完本组再打 8 号、母球落袋算犯规。至于要不要指袋报袋、三角框怎么摆、开球后是否定组、贴球与跳球怎么判、犯规后是手中球还是线后开球，中式八球的民间打法与美式八球的职业规则并不相同，WPA 一类的文本各地也各取所需，开局前讲清最省力。
