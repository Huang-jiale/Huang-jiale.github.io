## 先准备一张正方形的纸

绝大多数折法都从一张<strong>正方形</strong>纸开始。若手头只有长方形纸，先折出一个正方：把一个短边对齐到长边压出折痕，沿这条线把多余的纸条折掉或裁掉，剩下的就是正方形。

起步只需一张纸和一张平整桌面。选纸看两点：薄而挺的纸更容易压出清楚折痕；太软太厚的纸到后面几层会鼓起来。

## 先看懂看图用的符号

折纸教程几乎全靠<strong>符号</strong>说话。先记牢几条线型：谷折线一般画成虚线，山折线画成点划线（长短划相间），箭头表示要折过去的方向，单独的翻转符号表示把整张纸翻一个面。还要分清"只折一层"和"折全部层"——同一句指令，作用在某一层还是全部层，结果完全不同。看符号先想手上的动作：这条线是要向前凹进去、还是向后凸出来。

![图 2](/images/kb/origami/origami-fig2.svg)*图 2｜四行图例，每行左边是线型本身，右边是它的常见名称，读任何图解前先对照这张。*

## 两种最基本的折法：谷折与山折

<strong>谷折</strong>是把纸朝自己这侧向前折，折痕处向下凹，像一个山谷，图解多用虚线。山折方向相反，把纸朝背面向后折，折痕处鼓起一道山脊，多用点划线。两者只差向前还是向后，却决定后面每一步对不对。

每折一下都先<strong>对齐</strong>边和角，再用指甲或硬物沿折痕<strong>压平</strong>（也叫刮平）。下面这张对照图，左边是谷折、右边是山折，方框都是同大小的正方形。

![图 3](/images/kb/origami/origami-fig3.svg)*图 3｜两张同样大小的正方形并排：左图上是一条虚线配向上翻的箭头，右图上是一条点划线配向下压的箭头。*

## 常用基本折法：照着动作做就行

下面每种都用动作描述，只讲手怎么动。练习先慢、先小，把对齐和压平做扎实。

- 对边折（也叫书形折）：两条对边对齐，中间压出一条直折痕，展开后得到一条中线。
- 对角折：两个对角对齐压平，展开后得到一条对角折痕。
- 双向对折：横竖各对边折一次，展开得到十字折痕，是很多起手的底图。
- 收出三角形：沿十字折痕把左右两边向内合拢、上下压平，收出一个三角形——这种收法各地叫法不同，双三角、双三角基都常见。
- 兔子耳朵折：接着上一步，把三角形左右两个角分别向上、向下翻开，做出两片耳朵。这一步各地叫法也略有出入。
- 花瓣折（也叫收角，常见译名并不统一）：把菱形的几个锐角依次向上折起、压平，收成更紧的形状。
- 逆向折：让一个角连同它带的纸层一起从内部翻折过去，改变角度而不在正面留新折痕。
- 湿折：属于部分进阶玩法，用少量水把稍厚的纸微微润湿后再定型，干后折痕更持久。

## 常见的"基"：反复出现的起手结构

"基"指很多造型共用的起手结构。同一个结构，不同作者、不同地方常翻成不同的名字，所以这一节一律写成"常见译名"，不把哪一个当成通用标准。

- 风筝基：上窄下宽的四边形，常见于狐狸、小狗一类造型。
- 双三角基：把纸收成一组三角形的起手，各地也叫双三角。
- 鱼基：带一条长尾巴的收角起手，常见译名就叫鱼基。
- 水雷基：鼓鼓的多面起手，有的地方也叫水雷。
- 花瓣基：也译作百鸟基、鸟基一类，各地叫法并不统一。
- 风车基：四角向外翻、形似风车的起手，常见译名有风车基。
- 盒子基：折出一个立方体凹槽的起手。
- 水仙花基：多个尖角向中心聚拢的常见起手。
- 青蛙基：做腿部常用的起手，各地也有别的叫法。

| 术语 | 类别 | 含义 |

| 山折 | 折法 | 向后折，折痕处向上凸，多用点划线。 |

| 对齐 | 基本功 | 边对边、角对角先摆正，再压折痕。 |
| 预折 | 动作 | 正式折叠前先轻折一道，做定位。 |
| 开褶 | 动作 | 沿已有折痕把纸撑开、摊平。 |
| 内翻折 | 动作 | 把一个角往纸的内部翻折过去。 |
| 外翻折 | 动作 | 把一个角往纸的外部翻折出来。 |

## 新手最常踩的坑

> <strong>坑一：不先对齐就压。</strong>边或角差一点点，压死就成了永久偏差；越往后越难纠正。
> <strong>坑二：折痕没刮平。</strong>痕迹浅、后面全靠它定位，就会一路歪下去。
> <strong>坑三：分不清"一层"和"全部层"。</strong>指令说哪层就只动哪层，动手前先数清楚。
> <strong>坑四：把山折看成谷折。</strong>点划线和虚线方向相反，认错了整张就翻不过来。
> <strong>坑五：用非正方形纸硬折。</strong>基础步骤要求正方，长方形不先处理会一直多出一块。
> <strong>坑六：用指甲狠刮折痕。</strong>刮得太用力会把纸划破，宁可轻而多次。
> <strong>坑七：越到后面越用力。</strong>层数变多时反复捏，纸会起毛、变皱、松掉。

## 一页速查

| 要记的事 | 结论 / 口诀 |
| --- | --- |
| 起步纸形 | 正方形；长方形先折出一个正方 |
| 谷折的线 | 虚线，纸向前凹 |
| 山折的线 | 点划线（长短划相间），纸向后凸 |
| 箭头 / 翻转 | 箭头指折向；翻转＝整张纸翻面 |
| 一层还是全部层 | 按标注来，动手前先数层 |
| 基本功顺序 | 先对齐，再压平，别急着往下折 |
| 常见起手结构 | 十字折痕、双三角（各地叫法不同）等 |

> <strong>关于"叫法不统一"：</strong>同一个折法或同一个"基"，不同作者、不同地方常会翻成不同的名字（比如花瓣基、百鸟基这类说法并存）。本页一律按操作来写，不替读者判定哪个名字更正确；遇到拿不准的名字，以你手上那份图解为准即可。
