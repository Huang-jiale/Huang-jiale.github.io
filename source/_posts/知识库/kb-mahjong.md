## 一副牌有多少张

常见的一副牌，不带花牌是 136 张：万、条、筒三门花色各从一到九，每个号四张，合计 108 张；再加东南西北四张风牌和中发白三张三元牌，各四张，共 28 张。补上八张花牌就是 144 张。各地并不都用满：有的玩法只用 108 或 120 张，花牌算不算东西，房规差异很大。

## 一个回合是怎么转的

四人各坐一方，顺时针轮转。开局洗牌码成牌墙，掷骰子决定从哪段取牌，再按序抓牌：闲家起手 13 张，庄家多一张。之后进入循环：先摸进一张，判定能否和、能否杠，再打出一张到牌河，手牌张数随即复原。直到有人和牌，或者牌墙摸完，本局成为流局。

![图 2](/images/kb/mahjong/mahjong-fig2.svg)*图 2｜四个方框由左至右用箭头相连，下方那行是这套动作的硬约束。*

## 和牌的基本形

多数牌桌判定能不能和用的是同一个骨架：四组面子加一对将。面子分两种，顺子是同花色连号的三张，刻子是三张相同；将是另外两张相同的。凑不满这个形状就不能喊和。七对不属于这套骨架，只在承认它的规则里成立，怎么算以牌桌规定为准。

![图 3](/images/kb/mahjong/mahjong-fig3.svg)*图 3｜方块里的数字只演示"连号"与"相同"两种关系。*

## 五个动作：吃、碰、杠、听、和

- <strong>吃</strong> — 只有上家打出的牌能吃，用来凑顺子；多数玩法如此，也有的玩法整桌不许吃。
- <strong>碰</strong> — 任意一家打出的牌都能碰，手里两张相同的亮出凑成刻子；碰完必须打一张。
- <strong>杠</strong> — 四张相同：别人打出的第四张叫明杠，自己攥着叫暗杠，已碰出的刻子上补第四张叫加杠。杠完补摸一张再打一张。
- <strong>听</strong> — 只差一张就凑齐骨架的状态。要不要亮、能否改听，各家规则不同。
- <strong>和牌</strong> — 凑齐骨架并满足本桌的起和条件即为和：自己摸到叫自摸，别人打出叫点炮，点炮方通常承担更多。

## 术语速查

表里只放牌桌上真会说出口的词条，类别按作用分。

| 术语 | 类别 | 含义 |
| --- | --- | --- |
| 面子 | 牌型组 | 顺子与刻子的统称。 |
| 顺子 | 牌型 | 同花色相连的三张。 |
| 刻子 | 牌型 | 三张一模一样的牌。 |
| 将／对子 | 牌型 | 两张一模一样的牌。 |
| 字牌 | 牌类 | 风牌与三元牌的合称。 |
| 搭子 | 手牌结构 | 差一张就能成面子的两张。 |
| 边张 | 听牌型 | 搭子缺头或缺尾，例如一和二只等三。 |
| 嵌张 | 听牌型 | 搭子缺中间那一张。 |
| 双碰 | 听牌型 | 手里剩两对，任意一对变刻子都能和。 |
| 单吊 | 听牌型 | 只剩一张不成对，等它的同类凑成将。 |
| 听牌 | 状态 | 差一张即凑齐骨架。 |
| 自摸 | 和牌方式 | 和的那一张是自己从牌墙摸进来的。 |
| 点炮 | 和牌方式 | 别人打出的那张正好让你和，打出者担下这一局。 |
| 杠上开花 | 和牌时机 | 杠后补摸的那一张直接和了；多数规则认它，记法各表不同。 |
| 海底捞月 | 和牌时机 | 用牌墙末张摸成；有的地方也算末张打出的和牌。 |
| 流局 | 局终 | 牌墙摸完仍无人和，本局按桌规重开或结算。 |
| 抢杠 | 特殊判定 | 别人加杠的那张恰好是你的和牌张，有的规则允许先一步和。 |
| 包牌 | 责任分摊 | 部分地方规则里，促成和牌的那张由某一家负责。 |
| 清一色 | 牌型 | 整副只用一个花色，多数规则视作大牌型。 |
| 七对 | 牌型 | 七个对子组成的非骨架牌型，需规则承认。 |
| 缺门 | 手牌要求 | 四川麻将常见打缺：一门花色要全部打光。 |
| 牌河 | 桌面区域 | 各家打出的牌摊在身前的位置。 |

## 新手最常踩的坑

> <strong>坑一：碰完忘了数牌。</strong>碰要把两张亮出去再打一张，手牌张数随之变化；不每巡数一遍就会多一张少一张，本局作废。
> <strong>坑二：见牌就碰。</strong>把本可连成顺子的两张拆出去做刻子，骨架反而更难凑。碰之前先问：剩下的搭子还接得上吗。
> <strong>坑三：做大牌一直不放听。</strong>还有可换的牌就死撑着不听，常被先和的人结束本局。多数牌桌上，先听比凑大更实在。
> <strong>坑四：拿自家规则去算别家的牌。</strong>番与计分各家牌桌并不一样，事前把用哪一套说定，比事后争论划算。
> <strong>坑五：错报和牌形。</strong>差一张就喊和，或把两对当刻子，不少规则对虚报另有处置。喊和前把四组和那一对数一遍。
> <strong>坑六：摸与看的顺序搞反。</strong>次序是先摸进、再判定、最后出手；急着出手会漏掉刚摸来的那张和牌张。
> <strong>坑七：拆掉将牌去凑顺子。</strong>那一对是底座，除非另有第二对，拆将往往同时毁掉两组。

## 番与计分：为什么这一页不写数字

番、花、分这些词，在不同体系里指的不是同一件事。国标、广东、四川、日本、台湾的规则，以及推倒胡、血战、竞技规则，各有各的番种表和封顶线，同一副牌算出的结果常常差很远，地方规则之间更是不统一。所以这一页不写具体番数：有没有起和门槛、封顶封到哪、某个牌型记多少，全部以你们牌桌的规定为准。

上桌前把三件事说定：用哪套番种表、要不要门槛、封顶线在哪。也有的桌子直接选推倒胡式的简化打法，不设门槛，凑齐骨架即和。争论几乎都出在这一步，而不是牌技。

## 一页速查

| 要记的事 | 结论 |
| --- | --- |
| 一副牌不带花 | 136 张：万条筒 108 + 字牌 28 |
| 带花牌 | 144 张；也有 108 或 120 张的打法 |
| 起手张数 | 闲家 13 张，庄家多一张 |
| 一个回合 | 摸一张 → 判定 → 打一张，张数复原 |
| 和牌骨架 | 四组面子 + 一对将；七对等需规则承认 |
| 吃的来源 | 只吃上家打出的那张，多数玩法如此 |
| 杠的种类 | 明杠／暗杠／加杠，杠后要补摸一张 |
| 一局终了 | 有人和牌，或牌墙摸完成流局 |
| 番与计分 | 必须点名规则体系，否则数字无据 |

> <strong>关于"版本差异"：</strong>吃牌资格、杠后从哪补牌、有无起和门槛、流局怎么结算、花牌算不算数，这几项在地区与房规之间差别最大。本页凡是写了"常见""多数""有的地方"的句子，都是在提示你上桌先问一句；凡是没给的数字，就不该由一页速查替你定。
