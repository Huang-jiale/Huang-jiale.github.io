## 先看懂一局是怎么走完的

开局前台面上是 15 颗红球、六颗彩球加一颗母球，一共 22 颗球。彩球各回置球点，母球由开球方在开球区放好。开球只要合法地碰到红球，一般不罚分，之后双方轮流上台。

![图 1](/images/kb/snooker/snooker-fig1.svg)*图 1｜②里彩球进袋会被摆回原点，④清彩时进袋的球不再摆回。*

主线是红球与彩球交替：每打进一颗红球，就指定一颗彩球来打；彩球进袋后按那颗球的分值计分，随后被取出摆回原点，等下一颗红球。红球全部打完才进入清彩阶段，通常从最低分的那颗开始逐颗清完，进一颗少一颗。红球每进一颗只记 1 分，配一颗高分彩球能多拿几分。

## 球的数目与分值

红球的分值固定为一分；六颗彩球各有固定分值，见图二。最需要背的就是这六行：谁值几分、进袋后要不要摆回。

![图 2](/images/kb/snooker/snooker-fig2.svg)*图 2｜色块从低到高排成一行。棕球常被叫作咖啡球，是同一颗球的不同叫法。*

把分值连起来算就明白一杆的上限：红球阶段反复进一红配一彩，最后清彩一颗不落，一般公认的单杆最高是 147 分。

## 第一次上台，照着做就行

- 摆球：母球放在<strong>开球区</strong>内不要压线，红球码成三角形。
- 喊球：出杆前说清要打哪颗。需要指定的球，<strong>不指定就等于没定</strong>。
- 出杆：架杆手压实台呢，用<strong>中等力度</strong>推，别一上来就发力。
- 停手：球没停稳别再碰母球，判罚多发生在这种时候。
- 让位：没进指定球就把球杆交给对手，别在台面上磨蹭。

## 核心规则

- <strong>击球顺序</strong> — 红球还在台上时走红球与彩球交替；红球打完才换成按分值排好的清彩顺序，这段顺序常见是固定的。
- <strong>彩球的摆回</strong> — 红球阶段彩球进袋只为计分，随后摆回原点；进了清彩阶段通常就不再摆回。
- <strong>计分</strong> — 进红球记 1 分，进彩球按那颗球的分值算；分数只从进袋来，不靠时间累积。
- <strong>犯规与罚分</strong> — 常见犯规是母球落袋、什么都没碰到、先碰错球。罚分通常按这次击球涉及的球分值算，常见下限 4 分，也有算得更高的写法。
- <strong>斯诺克与自由球</strong> — 用球挡住母球看目标球的线路，就是把对手做成斯诺克。常见处理是：确实打不到时可指定一颗自由球，这颗球怎么算分以当场规则为准。
- <strong>一局胜负</strong> — 多数按双方累计总分定胜负；分差实在拉不开时，常见是直接认输，也有继续清完的。

## 台面与球的摆法

常见的斯诺克台子大约 12 英尺长（约 3.6 米），比常见的中式台子更长、袋口更圆，各地场馆尺寸并不完全一致。要认的东西不多：四边那圈有弹性的边叫库边，六个口子是袋口；靠开球那一端有一条开球线，线外的半圆就是开球区，俗称 D 区。

![图 3](/images/kb/snooker/snooker-fig3.svg)*图 3｜母球开局只能放在半圆内，彩球摆回时回的就是那几个点；图只表示方位。*

彩球摆回时若原点已被占，常见处理是放到最近的空点上，各场馆细节不太一样。

## 术语速查

下表只列会当面说出口的词。同一件事各地叫法不同，有分歧就以当场约定的规则为准。

| 术语 | 类别 | 含义 |
| --- | --- | --- |
| 母球／白球 | 器材 | 唯一能手放的球，别的球都归它撞。 |
| 目标球 | 规则 | 这一杆打算送进袋的那颗球。 |
| 指定球 | 规则 | 出杆前说定的球，常见先说后打。 |
| 落袋／pot | 计分 | 球进口才算得分，卡袋通常算没进。 |
| 开球／break-off | 规则 | 第一杆打散红球堆，常见是轻推。 |
| 防守／做安全球 | 战术 | 不追分，先把母球藏起来。 |
| 斯诺克 | 战术 | 让对手看不见目标球的障碍局面。 |
| 自由球／free ball | 规则 | 常见是对手犯规后拿一颗别的球顶上，罚分按当场规则。 |
| 单杆／break | 计分 | 一次上台连续打进的分，上限 147。 |
| 摆回原点／respot | 规则 | 把进袋的彩球放回置球点。 |
| 开球区／D | 台面 | 开球线外的半圆，母球开局只能放这。 |
| 置球点／顶球点 | 台面 | 彩球该待的标记点，沿中线排开。 |
| 库边／cushion | 台面 | 四边那圈有弹性的边。 |
| 袋口 | 台面 | 六个进球的口子。 |
| 低杆／screw | 杆法 | 打母球中下部，撞完往回缩。 |
| 高杆／follow | 杆法 | 打母球中上部，撞完往前跟。 |
| 加塞／side | 杆法 | 打两侧换反弹角，新手容易打滑。 |
| 弧线／扎杆 | 杆法 | 抬杆尾让母球走弯线绕障碍。 |
| 贴球／touching ball | 规则 | 母球贴上目标球，常见按已碰到来判。 |
| 决胜局 | 赛制 | 盘数打平后定胜负的那一局。 |
| 犯规／foul | 规则 | 母球落袋或先碰错球，通常要吃罚分。 |

## 新手最常踩的坑

> <strong>坑一：只盯目标球，不管母球落在哪。</strong>斯诺克打的是下一杆的位置，出杆前先想清楚母球停在哪，不然打进这颗也没用。
> <strong>坑二：架杆手没压实，皮头打滑。</strong>手指贴住台呢、指尖微翘成槽；出杆那一下手一软，球就偏，还容易判犯规。
> <strong>坑三：红球阶段乱选彩球，把自己做死。</strong>能打进不等于合适：占了高分球的线路，或让母球停在下一颗红球够不着的地方，常见是立刻交出球权。
> <strong>坑四：以为彩球进袋就不摆回。</strong>红球还在台上时，彩球只是去计分，进袋后会被摆回原点；把它当成"少一颗"来排顺序，整段计划就错了。
> <strong>坑五：算罚分时按自己想要的数字算。</strong>常见处理是按这次击球涉及的球分值来罚，下限通常是 4 分，不是随手一个数。
> <strong>坑六：开球太用力，留一个长台给对手。</strong>力气大不等于散得开，母球常自己滚进袋或停在太好打的位置；轻推、贴回库边更稳妥。
