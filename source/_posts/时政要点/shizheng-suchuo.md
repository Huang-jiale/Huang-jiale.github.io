## 易混提法对照（考前一晚必看）

| 易混点 | 正确 | 常见错误写法 |
| --- | --- | --- |
| 政绩观学习教育 | 总要求＝立党为公、为民造福、科学决策、真抓实干 | 与「一体推进学查改」（抓手）对调 |
| 网络生态治理 | 分众化、精准化实施机制 | 统一化、精准化 |
| 依法治国 | 抓住<strong>领导干部</strong>这个关键少数 | 基层干部 |
| 国防政策 | <strong>防御性</strong>国防政策 | 中立性国防政策 |
| 新质生产力路径 | <strong>科技创新和产业创新</strong> | 文化创新 |
| 收入分配 | <strong>居民</strong>收入增长和经济增长同步 | 企业收入 |
| 金融改革 | 金融<strong>供给侧</strong>结构性改革 | 金融需求侧改革 |
| 产能提升行动 | 新一轮<strong>千亿斤</strong>粮食产能提升行动 | 万亿斤 |
| 利益补偿机制 | 粮食产销区省际<strong>横向</strong>利益补偿 | 纵向 |
| 永久基本农田 | <strong>优进劣出</strong>管理机制 | 劣进优出 |
| 兜底保障 | 发挥<strong>社会救助</strong>兜底保障作用 | 社会保险 |
| 首都都市圈格局 | 一核两翼、双城多点、双廊多圈 | 双核共进 |
| 国家安全 | 把捍卫<strong>政治</strong>安全摆在首位 | 国土安全 |
| 公共安全治理 | 从事后处理向<strong>事前预防</strong>转型 | 事中控制 |
| 城市工作 | 工作重心转向更加注重<strong>治理投入</strong> | 建设投入 |
| 最大优势 / 最大政绩 | <strong>党的领导</strong>是最大优势；<strong>为民造福</strong>是最大政绩 | 以人民为中心＝最大优势 |

| 海南封关 | 「一线」放开、「二线」管住、岛内自由 | 一线管住、二线放开 |
| 福建舰动力 | <strong>常规动力</strong>电磁弹射 | 核动力 |
| 天问系列 | 天问二号＝<strong>小行星</strong>采样返回；天问一号＝火星 | 天问二号探测火星 |
